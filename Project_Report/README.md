# PRT564 Assessment 4 — Charity Size Classification

This folder contains the classification stage of the ACNC Charity Analytics project: predicting whether an Australian charity is **Small**, **Medium**, or **Large** from its operational and financial characteristics, using the ACNC Charity Register enriched with the 2023 Annual Information Statement (AIS).

The integrated dataset (`acnc_final.csv`) is carried over from Assessment 2. The scripts here perform the classification-specific preprocessing, exploratory data analysis, model training, evaluation, and a deployment demonstration.

---

## Preprocessing run order

Run these from inside this folder. Each step writes the CSV the next step reads, starting from `acnc_final.csv`:

```
encode.py               # encode target (Small=0, Medium=1, Large=2) -> acnc_encoded.csv
new_feat.py             # fill financials, engineer 4 new features    -> acnc_features.csv
final_dataset.py        # select the 62 feature columns               -> acnc_classification.csv
split_and_feat_scale.py # 80/20 train/test split + scaling check
```

## Modelling and evaluation

Once `acnc_classification.csv` exists, these run independently:

| Script | Purpose |
|--------|---------|
| `nb.py` | Gaussian Naive Bayes |
| `random_forest.py` | Random Forest (1,000 trees, balanced) |
| `svm.py` | Linear-kernel SVM |
| `evaluation.py` | Side-by-side metrics for NB / Decision Tree / Random Forest |
| `cross_validate.py`, `5_fold_cv.py`, `svm_full_cv.py` | Cross-validation (10-fold and 5-fold) |
| `gridsearchCV.py` | Random Forest hyperparameter search |
| `iqr_outliers.py` | IQR outlier test (with/without comparison) |

The EDA and results figures (`.png` files in this folder) are produced by the visualisation scripts (`class_distribution.py`, `correlation_analysis.py`, `eda_feature_by_class.py`, `boxplot_analysis.py`, `confusion_matrix.py`, `ROC_AUC.py`).

## Deployment demonstration

```
train_and_save_model.py   # trains the final Random Forest, saves it -> rf_charity_size.joblib
deploy_predict.py         # reloads the saved model, reproduces test accuracy
```

`rf_charity_size.joblib` is generated by `train_and_save_model.py` and is not committed due to size. Run that script first; `deploy_predict.py` then loads the file and confirms the reloaded model reproduces the reported test accuracy (91.47%) without retraining.
